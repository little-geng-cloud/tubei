# 途备 Agent（对标你给的化学有式模板，完全同格式）

基于 Kiro 开发的智能旅行规划 Agent，帮助用户根据目的地、出行天数、同行人员，自动生成完整旅行方案，包含每日行程规划、分日穿搭推荐、出行打包清单，并附带预算预估、避坑提示。

## 一、项目概述

### 1.1 功能简介

**途备 Agent** 是一体化自助旅行规划助手。
核心能力：

- 出行信息采集：对话式收集目的地、出行时间、同行人员、游玩偏好、预算、特殊限制
- 行程编排：生成每日景点、游玩时长、交通、特色美食，自带备选景点
- 分日穿搭推荐：根据目的地同期气候、出行天数、同行人群生成每日穿搭
- 打包清单生成：自动输出分类物资清单，区分必带 / 可选，适配场景专项物品
- 多轮迭代：用户随时修改需求，整套方案自动重生成
- 辅助信息：预算拆解、景点预约提醒、民俗与消费避坑提示

### 1.2 核心特性

- 场景自适应推理：海岛 / 高原 / 城市 / 徒步自动切换穿搭与打包物品
- 行程节奏控制：老人、婴幼儿同行自动降低每日行程强度，减少赶路
- 结构化输出：固定 Markdown 模板，手机直接查看、复制保存
- 多子 Agent 协同（Kiro Crew）：信息采集、穿搭计算、行程编排、物资清单模块解耦
- 多轮对话迭代：支持修改天数、目的地、同行人，一键重新生成全套方案

## 三、部署启动流程

### 3.1 环境要求

Kiro IDE 已安装
项目目录放置在 Kiro 工作区

### 3.2 部署步骤

步骤 1：创建 Agent 配置文件
在项目根目录创建 `.kiro/agents/travel-planner.md`

```
---
name: 途备Agent
description: 智能旅行规划助手，生成每日行程、分日穿搭、出行打包清单
model: miniMax-m2.5
tools: ["read", "web_search", "web_fetch"]
---
# 下面粘贴主Agent系统提示词
你是【途备Agent】，智能旅行规划助手。
## 核心职责
通过对话收集用户出行信息，调度子Agent生成全套旅行方案，支持多轮修改迭代，输出Markdown结构化旅行计划。
采集字段：目的地、出行起止日期/总天数、同行人员（人数+类型：成人/老人/婴幼儿）、旅行偏好（城市逛吃/自然风光徒步/海岛休闲/人文古迹）、预算档位（经济型/中端舒适/轻奢）、特殊限制（体力限制、饮食禁忌、是否自驾）。
信息缺失时，一次只追问一项缺失信息，不要一次性抛出大量问题。
信息收集完整后，调用Kiro Crew子Agent协同：信息采集Agent、天气&穿搭Agent、行程编排Agent、物资清单Agent。

## 输出规范
固定Markdown结构：
1. 基础出行信息
2. 每日行程规划
3. 每日穿搭推荐
4. 出行打包清单（✅必带 / ⭕可选）
5. 出行提示&避坑指南
6. 预算预估

## 规则
1. 带老人、幼儿自动降低行程强度，避免长时间赶路。
2. 根据目的地场景自动适配穿搭和物资（海岛/高原/雨季/冬季）。
3. 用户修改出行条件，重新生成完整全套方案。
4. 末尾增加免责声明：本方案仅作为旅行规划参考。天气为同期历史参考，景点开放、预约政策以景区官方公告为准；不提供实时机票酒店预订，出行前请再次核对相关信息。
5. 输出简体中文，结构清晰，适合手机阅读。
```

步骤 2：加载 Agent
Kiro 会自动扫描 `.kiro/agents/` 目录，加载自定义 Agent。如需手动刷新：
打开命令面板：`Ctrl+Shift+P`
输入 `Kiro: Reload Agents`
回车执行

步骤 3：切换到 Agent
方式一：UI 操作
点击聊天输入框底部的 Agent 名称
从列表中选择 `途备Agent`

方式二：命令切换

```
/agent swap 途备Agent
```

### 4.2 使用示例

示例 1：家庭短途游

> 
> 用户输入：目的地青岛，4 天，两大一小，城市 + 海边休闲，中端预算
> Agent 输出：

# 【途备 Agent 旅行方案】

## 基础出行信息

目的地：青岛；出行天数：4 天；同行：2 成人 + 1 幼儿；风格：城市 + 海边休闲；预算：中端舒适

## 一、每日行程规划

Day1：抵达青岛，栈桥散步，傍晚八大关。游玩 2~3h。

> 
> 提示：八大关无门票，傍晚拍照最佳；本地交通：地铁 + 打车；晚餐推荐海鲜水饺，避免景区高价大排档。
> Day2：崂山浅游览（选择平缓线路，带孩子不爬山）
> Day3：小麦岛公园 + 五四广场，看海边日落
> Day4：城市老街区闲逛，返程

## 二、每日穿搭推荐

Day1：短袖 T 恤 + 薄长裤，薄防风外套；鞋子：休闲运动鞋；配饰：遮阳帽
Day2：短袖 + 短裤，薄外套备用；鞋子防滑运动鞋；海边紫外线强，墨镜必备
Day3：同上，可备一套替换衣物，玩水容易打湿
Day4：长袖薄上衣，返程方便

## 三、出行打包清单

✅必带物品
证件：身份证、儿童户口本
电子设备：手机、充电器、充电宝
药品：儿童退烧药、肠胃药、创可贴、驱蚊液
其他：防晒霜、儿童防晒帽
⭕可选物品：沙滩玩具、折叠推车、泳衣

## 四、出行提示 & 避坑指南

1. 海边餐厅谨慎选择，不要在栈桥周边大排档高价消费；
2. 小麦岛周末人流量巨大，建议早 8 点前往；
3. 海边昼夜温差大，傍晚海风偏凉，随身带薄外套。

## 五、预算预估

住宿：4 天约 1600；餐饮：1200；门票：300；交通：500；合计预估 3600 元

> 
> 温馨提示：本方案仅作为旅行规划参考。天气为同期历史参考，景点开放、预约政策以景区官方公告为准；不提供实时机票酒店预订，出行前请再次核对相关信息。

## 五、核心功能详解

### 5.1 场景自适应推理

自动识别旅行类型，加载对应物资、穿搭规则：

- 海岛：泳衣、防水袋、高倍防晒
- 高原：分层防风穿搭、高原防护物资
- 城市逛吃：轻便穿搭，物资精简
- 徒步：护膝、登山杖、速干衣物

### 5.2 行程强度自动控制

- 同行含老人 / 婴幼儿：减少爬山、长距离移动，增加休息时间，优先平缓景点
- 单人青年：可适度增加徒步、远距离景点

### 5.3 多轮迭代更新

用户可随时修改：出行天数、目的地、同行人员、预算、游玩风格。
Agent 接收修改指令后，重新调用子 Agent，完整生成全套更新后的行程、穿搭、打包清单。
